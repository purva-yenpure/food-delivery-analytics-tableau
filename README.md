# Food Delivery Analytics using Tableau

## 📌 Project Overview

The food delivery industry generates large amounts of data related to customer orders, cuisines, cities, order values, meal types, and delivery performance. This project uses Tableau to analyse food ordering data and transform it into meaningful business insights.

The project focuses on understanding customer preferences, order demand, spending patterns, and delivery performance through interactive dashboards.

## 🎯 Objectives

- Analyse order demand across different cities.
- Identify popular cuisines and meal types.
- Analyse customer spending patterns.
- Study delivery-time distribution and city-wise delivery performance.
- Create interactive dashboards for different business stakeholders.
- Generate actionable recommendations from the analysis.

## 📊 Dataset

The dataset contains 1,000 food delivery orders with attributes including:

- Order ID
- Order Date
- Order Time
- City
- Cuisine
- Meal Type
- Order Value
- Delivery Fee
- Time Taken for Delivery
- Total Customer Spend

## 🔍 Key Insights

- Mumbai has the highest order volume.
- Fast Food is the most popular cuisine.
- Dinner is the highest-demand meal period.
- Biryani has the highest average order value.
- The average delivery time is approximately 37.59 minutes.
- Most orders are concentrated around the 35–40 minute delivery range.
- Chennai has the highest average delivery time.

## 💡 Recommendations

- Increase delivery capacity in high-demand cities.
- Allocate additional delivery resources during dinner hours.
- Maintain sufficient restaurant and delivery-partner availability for popular cuisines.
- Focus on reducing delivery times during peak periods.
- Improve delivery efficiency to enhance customer satisfaction.
